# 誕生日ARG 本番用・静的HTML版

このフォルダだけで動く、HTML／CSS／最小限のJavaScript版です。React、TypeScript、ビルド作業は不要です。

## まず見るファイル

- `index.html`：QRコードから開く「WEB MEMORY ARCHIVE」検索トップ
- `misaki/`：美咲ブログのトップと全記事
- `yuka/`：由佳ブログのトップと全記事
- `joji/early.html`：条司ブログの2021年10月22日保存トップ
- `joji/late.html`：条司ブログの2021年11月8日保存トップ
- `joji/j01.html`〜`j14.html`：条司の各記事
- `market/`：羽化珠の出品ページと真田商会プロフィール
- `religion/`：至寧堵宗 R-01〜R-05
- `search/`：7種類の検索結果ページ
- `extras/anonymous-board.html`：印刷物確認用の匿名掲示板。Web上の正規導線からはリンクしていません

## よく行う修正

### 記事本文を直す

該当するHTMLをテキストエディタで開き、`<div class="article-copy">` 内の文章を修正します。

例：美咲の「ママとおそろい」は `misaki/m07.html` です。

### 画像を差し替える

`media/` 内の同名ファイルを上書きします。HTML側を直さずに差し替えられます。

- `r02.webp`：安寧の集い
- `r03.webp`：羽化珠三珠
- `mk01.webp`：羽化珠の出品写真
- `shinedoshu-crest.svg`：至寧堵宗の紋章
- `snds-logo.svg`：真田商会ロゴ

### 色・文字サイズ・余白を直す

`css/site.css` を編集します。Archive、美咲、由佳、条司、真田商会、至寧堵宗の順にコメントで区切っています。

### Archiveの検索語や行き先を変える

`js/site.js` 冒頭の `searchRoutes` だけを修正します。JavaScriptは検索と画像拡大にしか使用していません。

## 公開時の置き方

このフォルダの中身を、そのまま公開先のルートへ置きます。入口は `index.html` です。サブフォルダ構成は変えないでください。

検索結果や記事は通常のHTMLリンクでつながっています。プレビュー用タブ、制作メモ、全ページへの直通リンクはありません。

- 匿名掲示板用の正確な自宅間取り図
- R-05「記録写真03」の始まりの地（大田区）
