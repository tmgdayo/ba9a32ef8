# 誕生日ARG 本番用・静的HTML版

このフォルダだけで動く、HTML／CSS／最小限のJavaScript版です。React、TypeScript、ビルド作業は不要です。

## まず見るファイル

- `index.html`：QRコードから開く「WEB MEMORY ARCHIVE」検索トップ
- `misaki/`：美咲ブログのトップと全記事（`m00-xxxxxxxx.html`、`m01-xxxxxxxx.html`等）
- `yuka/`：由佳ブログのトップと全記事（`y00-xxxxxxxx.html`、`y01-xxxxxxxx.html`等）
- `joji/j00a-xxxxxxxx.html`：条司ブログの2021年10月22日保存トップ
- `joji/j00b-xxxxxxxx.html`：条司ブログの2021年11月8日保存トップ
- `joji/j01-xxxxxxxx.html`〜`j14-xxxxxxxx.html`：条司の各記事
- `market/`：羽化珠の出品ページと真田商会プロフィール
- `religion/`：至寧堵宗 R-01〜R-05
- `search/`：6種類の検索結果ページと検索結果なしページ
- `extras/b01-xxxxxxxx.html`：印刷物確認用の匿名掲示板。Web上の正規導線からはリンクしていません

## よく行う修正

### 記事本文を直す

該当するHTMLをテキストエディタで開き、`<div class="article-copy">` 内の文章を修正します。

例：美咲の「ママとおそろい」は、ファイル名が `m07-` で始まるHTMLです。

### 画像を差し替える

`media/` 内の同名ファイルを上書きします。HTML側を直さずに差し替えられます。

- `r02.webp`：安寧の集い
- `r03.webp`：羽化珠三珠
- `m04.webp`：M-04の採点画面（人物なし）
- `y09.webp`：Y-09のLINE画面（公開用に連絡先名を切り落とした版）
- `mk01.webp`：羽化珠の出品写真
- `r05-03.jpg`：涅槃座の記録写真
- `r05-04.png`：羽化の教え
- `shinedoshu-crest.svg`：至寧堵宗の紋章
- `snds-logo.svg`：真田商会ロゴ

### 色・文字サイズ・余白を直す

`css/site.css` を編集します。Archive、美咲、由佳、条司、真田商会、至寧堵宗の順にコメントで区切っています。

PC用の指定は、ファイル後半の `Desktop layout` と `Desktop readability pass` にまとめています。画面幅760px以上でだけ有効になり、スマホ用の見た目には影響しません。

### 美咲の記事のハッシュタグを直す

各記事HTMLの末尾にある `<p class="misaki-hashtags">` 内を書き換えます。タグは記事本文の下、ハート表示の直前にあります。

### Archiveの検索語や行き先を変える

生成済みサイトでは、`js/site.js` 冒頭の `searchRoutes` だけを修正します。JavaScriptは検索と画像拡大にしか使用していません。

「法具」と「涅槃座」は検索結果ページを挟まず、それぞれ `religion/r04-xxxxxxxx.html` と `religion/r05-xxxxxxxx.html` を直接開きます。R-04／R-05は現在のプレイヤーへ表示されるページのため、Archiveの保存日時やSAVED COPY表示も付けていません。

## URLの推測防止

`index.html` 以外のHTMLは、管理用コードの後ろに8桁の接尾辞を付けています。例：`r04-7f3c9a1b.html`。R-04やJ-14などの管理用コードは残りますが、接尾辞が一致しなければページは開けないため、URLの連番だけを書き換えて先のページを見ることはできません。

接尾辞は制作データから再生成しても変わらない固定値です。HTML同士のリンクと検索先は自動的に同じ名前へ揃います。

## 記事の呼び方・文体

- 美咲の記事本文は句点「。」を使わず、改行で文の区切りを作ります。
- 由佳の記事では、娘を「娘」または「あの子」、夫を「夫」と書き、家族の実名は出しません。
- 条司の記事では、家族を「妻」「娘」と書き、家族の実名は出しません。
- 「赤井条司」は検索導線に必要な本人名なので、条司ブログのプロフィールだけに残しています。

## 公開時の置き方

このフォルダの中身を、そのまま公開先のルートへ置きます。入口は `index.html` です。サブフォルダ構成と、ファイル名末尾の接尾辞は変えないでください。

検索結果や記事は通常のHTMLリンクでつながっています。プレビュー用タブ、制作メモ、全ページへの直通リンクはありません。

## 補足

匿名掲示板の印刷物は `extras/` に収録しています。R-05の記録写真03・04も実画像へ差し替え済みです。
